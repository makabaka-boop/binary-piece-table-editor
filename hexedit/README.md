# HexEdit — 浏览器本地十六进制编辑器

在浏览器本地编辑不超过 **8 MB** 的二进制文件：文件不离开本机，不上传任何服务器。

## 运行

模块脚本与模块 Worker 需要通过 HTTP 访问（`file://` 无法加载）：

```bash
cd hexedit
python3 -m http.server 8080     # 或 npm run serve
# 打开 http://localhost:8080
```

## 测试

```bash
node test/run.mjs               # 或 npm test（需要 Node ≥ 18）
```

## 功能

- 十六进制表每行 16 字节，虚拟滚动（只渲染可视行），8 MB 文件流畅滚动
- 插入 / 删除 / 替换：HEX 半字节输入、ASCII 栏字符输入、Insert 键切换插入/覆盖
- 多步撤销 / 重做（Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z），连续输入合并为单步
- 搜索字节模式（十六进制或 UTF-8 文本），命中高亮、上一个/下一个跳转
- 全部替换（仅当搜索结果未过期时可用），整批一步撤销
- 导出当前内容（Ctrl+S），逐段生成并计算 SHA-256 摘要
- 剪贴板：复制为十六进制文本；粘贴自动识别十六进制或按 UTF-8 插入

## 架构

```
src/piece-table.js   编辑模型：原文件(只读) + 追加区(只增) 的范围引用（piece table）
src/mapping.js       位置迁移规则（光标/选区随编辑移动）
src/search.js        KMP 流式匹配（主线程与 Worker 共用）
src/search-worker.js 搜索 Worker：增量同步追加区，结果绑定修订号
src/sha256.js        增量式 SHA-256（导出边生成边算）
src/exporter.js      快照导出
src/hexview.js       虚拟化十六进制视图 + 编辑控制器
src/app.js           应用装配：文件、搜索客户端、替换、导出、状态栏
test/run.mjs         对拍测试（小数组参考实现 vs 片段表）
```

### 编辑模型（不为每次按键复制文件）

文档是一串**范围引用** `{orig, start, len}`，分别指向只读的原文件缓冲和只增不减的
追加区。每次编辑只做范围的切分与拼接（单次扫描，O(片段数+编辑数)），插入的字节
追加到追加区末尾；原文件按引用持有，从不复制。撤销记录保存正向编辑与逆操作
（删除前读出的旧字节）；同一输入会话的连续击键合并为一条撤销记录。

### 位置迁移

任何逻辑位置 `p` 经过编辑 `(pos, deleteLen, insertLen)` 后按统一规则迁移：
`p ≤ pos` 不动；`p ≥ pos+deleteLen` 平移；落入被删区间则收缩到 `pos`。
光标与选区端点在撤销/重做/批量替换后都经 `mapThrough` 迁移。测试用“令牌身份”
参考实现独立推导期望位置进行对拍。

### 搜索（Worker + 修订绑定）

Worker 持有文档镜像（原文件克隆一次，追加区按块**增量同步**），搜索请求只携带
片段表（很小）与新的追加块。KMP 以拉取流方式扫过片段序列，**跨范围命中**无需
拼接文档。结果随 `done` 回传**修订号**；此后任何编辑都会改变文档修订号，旧结果
立即在界面上标记为**已过期**，且“全部替换”被禁用——过期结果不能直接用于批量替换。

### 导出（快照语义）

`snapshot()` 是浅拷贝：片段数组从不原地修改、追加区只增不减，因此快照永久有效。
导出对快照逐段生成内容并增量计算 SHA-256，期间让出事件循环保持界面响应；
**导出期间的后续编辑不改变该份下载**的内容与摘要（测试覆盖）。

## 对拍测试

`test/run.mjs` 用小数组参考实现（`splice` + 每字节唯一令牌）对拍随机编辑历史：
插入/删除/替换/撤销/重做混合的数百次操作 × 多组种子，逐操作比对全文内容与
标记位置迁移；另有批量同坐标编辑（全部替换语义）、撤销分支（撤销后新编辑清空
重做栈）、跨范围命中、输入合并、SHA-256 标准向量与边界、导出快照等用例。

## 复杂度与限制

- 单次编辑 O(片段数)；片段数在正常编辑下为个位数。大批量替换（如 5 万处）后
  片段数约 10 万，此时单次击键约 5 ms，批量应用/撤销/重做约 100 ms（实测）。
- 撤销历史与追加区只增不减，长时间编辑会持续增长内存（8 MB 上限下可控）。
- 命中数上限 20 万（超出标记“已达上限”）。
